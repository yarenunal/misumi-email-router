# Email Router: AI-powered inbound email classification

> **Status: Under development.**

An AI-assisted system that classifies inbound customer emails (order, quote,
return, support, other), extracts data from attachments, matches customers,
and routes low-confidence cases to human review.

Inspired by the public Misumi USA / Atos case study on automating email routing
with Amazon Bedrock. This is an independent learning project, built locally
with open-source tools and synthetic data. It is not affiliated with Misumi,
Atos or AWS.

## Tech stack

Python, Ollama (local LLM), Pydantic
